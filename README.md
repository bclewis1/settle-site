# The Settlement — companion volume (static site)

An illustrated tour of the Mars-colony settlement in eleven chapters, rendered
as mid-century cutaway plates. Pure static HTML/CSS + optimised JPEG plates — no
build step.

- `index.html` — the landing page (chapter-card contents) + all chapters
- `style.css` — period typography + the chapter-card grid
- `plates/` — the render plates (web-optimised, ~1400px JPEG)

**Publish via GitHub Pages** (see the chat instructions): point Pages at this
folder's contents. The full-resolution source renders live under `../renders/*/output/`.
